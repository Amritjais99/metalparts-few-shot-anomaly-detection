## Metrics and thresholds
PRIMARY: image AUROC, per condition and equal-condition macro average; average AUROC across seeds, never average raw scores from independently calibrated seeds to create an undeclared ensemble.
Secondary: image AUPRC, pixel AUROC, AUPRO integrated through FPR=0.30, F1, false-alarm rate, recall, FPR@95% TPR (smallest achieved FPR at an empirical ROC point with TPR >=0.95; no interpolation), runtime and memory. Report exact denominators. Pixel metrics only where valid masks exist; disclose pixel grid/interpolation and approximation settings.
Source-performance retention: source image AUROC at adapted K minus corresponding source-trained K=0 AUROC, plus source threshold metrics; negative differences indicate forgetting. Use identical source-test IDs for each paired comparison.
Primary threshold: source-normal empirical 95th quantile (higher), computed at K=0 separately per model/source-training seed, numerical threshold frozen at K>0. Label all resulting K>0 threshold metrics exactly: "source-fixed threshold under score shift".
Controlled threshold table: total budget 20 = 10 fit + 10 disjoint calibration. Compare both thresholds on the SAME 10-adapted detector. Do not present all-20 versus 10+10 as a pure threshold effect.
Two to ten calibration images give only small-sample estimates; 11-14 historical source validation normals are also imprecise. No guaranteed 95% FPR control.
FPR@fixed TPR is a retrospective diagnostic using final test labels, not a deployable normal-only threshold.

## Paired bootstrap 95% confidence intervals
2026-11-14 clarification BEFORE executable freeze, requested by user: report reviewed capture-group counts separately for target normals and anomalies. A perceptual-hash candidate component is NOT a reviewed physical capture. If either class has fewer than 30 reviewed groups, or any candidate/verified giant component contains more than 50% of a class, use image-level class-stratified paired bootstrap and within-condition paired image-score permutation. Label both **conditional on image-level independence, potentially optimistic**. For a six-condition statistic, if any condition fails the grouping gate, use this declared image-level fallback for the whole comparison and disclose all condition counts. No new group identity is inferred from filenames or hashes. The P1 audit documents no verified physical capture identities, so the current six-condition study uses the fallback. This clarifies inference handling; it does not change fitting separation, splits, PCB NO-GO, or any scientific hypothesis.

Use 10,000 paired resamples, statistical RNG seed 20261112. Preserve matching image IDs and the entire vector of predictions across methods/K/seeds for each resampled unit. Compute each seed's AUROC, average seeds within condition, then average the six conditions equally. Conditions are fixed evaluation strata, not six independent bootstrap subjects.
Resample reviewed capture groups within each condition, normal/anomalous strata where group labels permit. If a verified capture group spans conditions, jointly resample that group and propagate its multiplicity across conditions. Do not split an established mixed-label group merely to stratify; use grouped bootstrap and reject replicates missing a class, reporting rejection rate.
If no defensible capture identity exists, use paired class-stratified image bootstrap and label CIs conditional on image-level independence, potentially optimistic. Seed SD is descriptive; bootstrap over images/groups conditional on the trained seeds does not estimate all training uncertainty.
Use percentile 2.5/97.5% intervals for effects and metrics. Report sample sizes, group definition and limitations. No significance claim from overlapping/nonoverlapping standalone CIs alone.

## ONE paired permutation test: image scores, not conditions
Only predeclared comparison: conv AE decoder+replay versus frozen DINOv2 memory variant, MetalParts target K=20.
Observed statistic T = (1/6) * sum over conditions [mean over paired seeds AUROC_A - mean over paired seeds AUROC_B].
Permute paired IMAGE SCORES WITHIN EACH CONDITION. For each image, randomly swap the two methods' score assignments, retaining labels and IDs. Use the SAME swap across its paired seeds. Do NOT permute six condition-level AUROC numbers or regard seeds as independent images.
Because the methods' raw score scales differ, first transform each method/seed/condition score vector to within-vector fractional midranks (ties preserved). This leaves its observed AUROC unchanged and prevents arbitrary units from dominating mixed-score permutations. Perform swaps on these paired rank-scores and recompute all AUROCs and T in each of 10,000 permutations. Two-sided p = (1 + number with abs(T_perm) >= abs(T_observed))/(10000+1).
Where defensible repeated-capture groups exist, use one swap for the whole group, including any occurrences across conditions. This still swaps image-score pairs, never whole conditions. Otherwise disclose image-level exchangeability as an assumption.
This test assumes exchangeability of paired rank-score assignments under its null, stronger than merely equal population AUROC. With dependent unknown identities its p-value is exploratory. No additional confirmatory p-values, McNemar, Holm or selection of a favorable comparison.
